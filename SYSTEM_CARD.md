# System Card: Agentic AI Civic Tutor

## 1. System Overview

The Agentic AI Civic Tutor is an AI-assisted educational system designed to support preparation for the French civic integration exam.

The system simulates a 40-question multiple-choice exam and provides:

- deterministic evaluation of answers  
- AI-generated bilingual explanations (French / English)  
- identification of weak knowledge areas  
- interactive learning through feedback and clarification  

The system combines structured data with language model outputs in a controlled workflow.

---

## 2. Intended Use

The system is intended for:

- learners preparing for the French civic exam  
- non-native speakers requiring structured explanations  
- educational and demonstrative purposes  

It is designed as a **learning support tool**, not as an official certification system.

---

## 3. System Architecture

The system follows a modular, agent-based design:

- QuestionAgent → selects questions  
- MCQAgent → generates multiple-choice options  
- EvaluationAgent → performs deterministic scoring  
- FeedbackAgent → generates explanations via LLM  
- AdaptationAgent → identifies weak areas  
- FinalReportAgent → summarizes performance  
- Governance Layer → enables user feedback and control  

Evaluation is deterministic, while explanation is AI-generated under constraints.

---

## 4. Data Sources

The system uses a structured dataset derived from publicly available civic exam materials produced by official French government sources.

The dataset is not included in this repository and is used for educational purposes only.

No personal data is collected or processed.

---

## 5. Outputs

The system produces:

- multiple-choice questions  
- correctness evaluation (correct / incorrect)  
- bilingual explanations  
- score and progress indicators  
- final performance report  

Outputs are partially generated by a language model and may vary in wording.

---

## 6. Human-in-the-Loop Mechanisms

The system includes basic Human-in-the-Loop controls:

- users can flag unclear or incorrect responses  
- users can request re-explanations  
- flagged cases are logged locally  

These mechanisms allow users to challenge the system and improve interaction quality.

---

## 7. Limitations

The system has several limitations:

- explanations are generated by an LLM and may vary in quality  
- distractor generation is heuristic-based  
- adaptation is session-based only  
- no persistent user profile or long-term learning tracking  

The system should not be used as the sole source of truth for civic knowledge.

---

## 8. Risks

Potential risks include:

- misunderstanding due to incorrect or unclear explanations  
- over-reliance on AI feedback  
- limited contextual adaptation for different learner levels  

These risks are mitigated through deterministic evaluation and user feedback mechanisms.

---

## 9. Governance and Safeguards

The system incorporates lightweight governance principles:

- deterministic evaluation to ensure correctness  
- constrained prompting to reduce hallucination  
- user-controlled interaction (flagging and re-explanation)  
- separation of evaluation and explanation  

The system is designed as a **bounded decision-support tool**, not an autonomous system.

---

## 10. Future Improvements

Planned improvements include:

- persistent user profiles and progress tracking  
- adaptive question selection  
- improved distractor generation using semantic similarity  
- expert review workflows for flagged responses  
- confidence scoring and escalation mechanisms  

---

## 11. Ethical Considerations

The system is designed with the following principles:

- transparency (clear separation of logic and AI outputs)  
- user agency (ability to challenge outputs)  
- fairness (neutral and respectful explanations)  
- accountability (traceable flagged interactions)  

The goal is to support learning while maintaining responsible AI practices.
